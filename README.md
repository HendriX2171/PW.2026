# PW.2026

Este projeto consiste em uma calculadora de IMC (Índice de Massa Corporal), desenvolvida com HTML, CSS e JavaScript. A aplicação permite que o usuário informe seu nome, peso e altura para calcular automaticamente seu IMC.

Além do resultado, o sistema apresenta uma classificação de acordo com o valor calculado e uma saudação personalizada conforme o horário do dia.

⚙️ Funcionalidades

Inserção do nome, peso e altura.

Cálculo automático do IMC.

Resultado apresentado com duas casas decimais.

Classificação de acordo com o IMC.

Saudação personalizada (bom dia, boa tarde ou boa noite).

Validação dos campos antes do cálculo.

💻 Tecnologias utilizadas

HTML5

CSS

JavaScript

🎯 Objetivo do projeto

Praticar conceitos fundamentais de desenvolvimento web, principalmente manipulação do DOM, variáveis, estruturas condicionais, funções e operações matemáticas com JavaScript.
